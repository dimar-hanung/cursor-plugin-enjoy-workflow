---
name: create-changelog-prod
description: Lanjutkan changelog production dari link Notion — deteksi project dan tanggal changelog terakhir, lalu tulis changelog sampai hari ini berdasarkan branch yang di-merge ke branch production (dari file .branch) di repo frontend dan backend, memakai command create-changelog.
---

Cek link notion dibawah. Project apa yang ada di changelog. Tanggal terakhir changelog kapan? 
Tambahkan changelog dari tanggal terakhir sampai hari ini, berdasarkan branch yang di merge ke branch production di repository frontend dan backend.
Dimana branch production? Di file `.branch`, tanya user jika tidak ada file .branch.

Gunakan command `create-changelog` untuk menulis changelog.
