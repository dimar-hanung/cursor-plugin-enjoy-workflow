# Grill Me

**Skip** trivial fixes, `/brainstorm`, `client-business-understanding`. `/plan-rules` may send you here to fill uncertainty — grill, then resume the plan.

- One question per turn. Recommend, ask, wait, record.
- Open the code first — do not ask what the repo already shows.
- Do not implement or edit `.plan.md` until the user confirms the decisions.

**Pre-plan** — no plan yet: settle scope, behaviour, schema, non-goals, then `/plan-rules`.

**Post-plan** — plan exists: grill **gaps only** (vague, TBD, mismatches). If none, stop — ready to implement. After confirm, patch the existing `.plan.md`.
